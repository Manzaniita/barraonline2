# Flujo de Trabajo Git: Commit y Push Obligatorio

Esta regla es de cumplimiento estricto en cada turno o tarea donde se modifique el código:
- Ante cualquier cambio, ajuste o creación de archivos en el repositorio, se debe realizar `git add`, `git commit` y `git push` automáticamente antes de dar por finalizada la respuesta.
- Los mensajes de commit deben ser semánticos, claros y en español (`style:`, `feat:`, `fix:`, `refactor:`, `perf:`).
- El repositorio remoto `origin` debe mantenerse siempre sincronizado.
